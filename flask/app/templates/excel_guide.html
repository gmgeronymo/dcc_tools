O que é esta planilha?

Esta planilha é um formulário em formato Excel que permite preencher todos os dados necessários para gerar um Certificado de Calibração Digital (DCC).

Em vez de digitar código JSON (uma linguagem técnica de programação), você simplesmente preenche as células do Excel como faria em qualquer planilha. O sistema converte automaticamente os dados para o formato digital.

Pré-requisito: Ter o Microsoft Excel, LibreOffice Calc ou Google Sheets instalado. O formato .xlsx é o padrão — não use .xls (formato antigo).
A planilha tem 11 abas:
1. Metadados Principais → Dados gerais do certificado 2. Software → Programas utilizados na calibração 3. Cliente → Dados do cliente 4. Informações Pertinentes → Condições ambientais (temperatura, umidade) 5. Declarações → Declarações fixas de rastreabilidade e incerteza 6. Rastreabilidade → Tabela de padrões utilizados 7. Método de Medição → Descrição do método e equação (se houver) 8. Mensurando → Definição do que está sendo medido 9. Índices → Parâmetros adicionais (faixa, tensão, frequência) 10. Resultados → Valores medidos com suas incertezas 11. Observações → Notas e observações adicionais

Como usar

Passo a passo:
1 Baixe a planilha modelo

Clique no botão de download no topo desta página. Use sempre a planilha modelo — não altere a estrutura das abas, linhas de cabeçalho ou nomes de colunas.

2 Preencha cada aba

Cada aba é descrita em detalhes nas seções a seguir. Campos em vermelho são obrigatórios; campos em verde são opcionais.

3 Não mude o formato dos dados

Não insira linhas ou colunas novas. Não altere os nomes das colunas. Não exclua linhas de exemplo — substitua os valores pelos seus dados.

4 Salve e envie

Salve o arquivo em formato .xlsx. Na página inicial da aplicação DCC Tools, use a seção "Gerar DCC a partir de arquivo Excel" para enviar a planilha.

Atenção: A planilha contém linhas de exemplo com dados fictícios. Substitua todos os valores pelos dados reais antes de gerar o certificado. Não apague a linha de cabeçalho (primeira linha de cada aba).

4. Informações Pertinentes

A aba Informações Pertinentes registra as condições ambientais durante a calibração, como temperatura e umidade relativa do ar. Cada linha representa uma condição.

Você pode usar dois formatos para temperatura e umidade:

Formato 1: Valor único

Quando a temperatura ou umidade foi medida e registrada como um valor único:

name | value | unc | k | unit | text | refType Temperatura | 23.2 | 1.0 | 2 | \degreecelsius | | Umidade rel. | 49 | 10 | 2 | \percent | |
Formato 2: Intervalo (mínimo e máximo)

Quando a temperatura ou umidade variou dentro de um intervalo durante a calibração:

name | value | value_min | value_max | unc | k | unit | refType Temperatura (intervalo) | | 20 | 25 | 1.0 | 2 | \degreecelsius | basic_temperature Umidade rel. (intervalo)| | 30 | 70 | 5 | 2 | \percent | basic_humidityRelative
Formato 3: Texto livre

Para informações que não são valores numéricos:

name | value | text | refType Informação textual | | Texto descritivo da condição... |
Descrição das colunas:
Coluna O que preencher Exemplo Tipo
name Nome descritivo da condição Temperatura Obrigatório
value Valor numérico único (não use se usar value_min/value_max) 23.2 Opcional
value_min Valor mínimo do intervalo (não use se usar value) 20 Opcional
value_max Valor máximo do intervalo (não use se usar value) 25 Opcional
unc Incerteza expandida da medição 1.0 Opcional
k Fator de abrangência (padrão: 2) 2 Opcional
unit Unidade de medida (formato D-SI) \degreecelsius ou \percent Opcional
text Texto descritivo (não use se usar value, unit ou interval) Condição observada... Opcional
refType Identificador padronizado (opcional, mas recomendado) basic_temperature Opcional
refType_min RefType para o valor mínimo (formato intervalo) math_minimum Opcional
refType_max RefType para o valor máximo (formato intervalo) math_maximum Opcional
Unidades comuns:
  • Temperatura em graus Celsius: \degreecelsius
  • Umidade relativa em percentual: \percent
  • Pressão atmosférica em Pascal: \pascal

5. Declarações

A aba Declarações contém dois campos textuais obrigatórios que são exibidos no certificado.

Campo O que preencher
Declaração de Rastreabilidade Texto que descreve a rastreabilidade metrológica dos resultados. Deve informar a qual padrão ou sistema (ex: SI, BIPM) os resultados são rastreados.
Declaração de Incerteza Texto padronizado que descreve como a incerteza de medição foi calculada. Deve mencionar o GUM e o fator de abrangência utilizado.
Tipo | Conteúdo Declaração de Rastreabilidade | Os resultados da calibração são rastreados ao Sistema Internacional de Unidades (SI)... Declaração de Incerteza | As incertezas expandidas de medição (U) relatadas são declaradas como a incerteza padrão combinada multiplicada pelo fator de abrangência k...
Textos padronizados: A DIMCI possui textos modelos para estas declarações. Consulte o modelo de certificado vigente para usar os textos corretos.

A aba Rastreabilidade lista os padrões de referência utilizados na calibração. Cada linha representa um padrão.

Esta aba é opcional — se não houver padrões a listar, deixe as linhas em branco.

Coluna O que preencher Exemplo
name Nome do padrão utilizado Conversor Térmico PMJTC
origem Instituição de origem do padrão PTB
certificado Número do certificado de calibração do padrão PTB 27812/2020
cod_id Código de identificação interno do padrão PR 394
name | origem | certificado | cod_id Conversor Térmico PMJTC | PTB | PTB 27812/2020 | PR 394 Resistor Padrão | Inmetro| DIMCI 1263/2024 | Lampe PR 465

7. Método de Medição

A aba Método de Medição descreve o procedimento utilizado na calibração. Cada linha representa uma etapa ou descrição do método.

Coluna O que preencher Exemplo
text Descrição textual do método de medição (pode ter mais de uma linha) As entradas de tensão do instrumento padrão...
equation Equação matemática do método (formato LaTeX). Opcional. \delta_u = \dfrac{U_ac}{U_dc}
text | equation Descrição do método de medição... | Segunda descrição do método (se necessário)... |
Formato de equações: Use notação LaTeX. Exemplos:
  • fração: \dfrac{numerador}{denominador}
  • subescrito: x_{indice}
  • sobrescrito: x^{expoente}
  • raiz quadrada: \sqrt{x}

8. Mensurando

A aba Mensurando define o que está sendo medido — o mensurando. Cada linha representa um tipo de grandeza medida. Pelo menos um mensurando é necessário.

Coluna O que preencher Exemplo Tipo
label Identificador único (sem espaços, em minúsculas) acdc Obrigatório
name Nome completo descritivo do mensurando Diferença AC-DC em tensão Obrigatório
col_name Nome da coluna na aba Resultados que contém os valores deste mensurando \delta_u Obrigatório
unit Unidade de medida do mensurando (formato D-SI) \micro\volt\volt\tothe{-1} Obrigatório
unc_relativa Digite Sim se a incerteza é relativa (adimensional), ou Não se é absoluta Não Obrigatório
relative_uncertainty_in_dcc Digite Sim para incluir a incerteza relativa também no bloco dcc:relativeUncertainty (schema 3.3.0) Sim Opcional
relative_unc_unit Unidade da incerteza relativa no DCC. Se vazio, usa \micro\one \micro\one Opcional
refType Identificador padronizado (opcional) basic_measuredValue Opcional
label | name | col_name | unit | unc_relativa | relative_uncertainty_in_dcc | relative_unc_unit | refType acdc | Diferença AC-DC em tensão | \delta_u | \micro\volt\volt\tothe{-1} | Não | Não | | rstdc | Resistência em Corrente Contínua | \m | \ohm | Sim | Sim | \micro\ohm\ohm\tothe{-1} |

Quando relative_uncertainty_in_dcc=Sim, a incerteza é estruturada no bloco dcc:relativeUncertaintyXmlList. Se for Não, o sistema segue a lógica legada de incerteza absoluta.

Unidades comuns:
  • Ohm (resistência): \ohm
  • Volt (tensão): \volt
  • Ampere (corrente): \ampere
  • Hz (frequência): \hertz
  • Watt (potência): \watt

9. Índices

A aba Índices define parâmetros adicionais que categorizam os resultados, como faixa de medição, tensão de teste ou frequência. Cada índice vira uma coluna na tabela de resultados.

Esta aba é opcional — se não precisar de índices, deixe em branco. Mas se houver um mensurando com índice na aba Resultados, o índice correspondente deve estar definido aqui.

Coluna O que preencher Exemplo
mensurando Identificador do mensurando ao qual este índice pertence (deve existir na aba Mensurando) acdc
label Identificador único do índice (minúsculas, sem espaços) faixa
name Nome descritivo do índice Faixa
unit Unidade do índice (formato D-SI) \volt
refType Identificador padronizado (opcional) teste_range
mensurando | label | name | unit | refType acdc | faixa | Faixa | \volt | acdc | voltage | Tensão | \volt | acdc | frequency | Frequência | \kilo\hertz |

10. Resultados

A aba Resultados é onde você insere os dados de medição propriamente ditos. Cada linha representa uma medição individual.

As colunas são geradas automaticamente a partir dos mensurandos e índices definidos nas abas anteriores:

  • Colunas fixas: mensurando, value, unc, k
  • Colunas dinâmicas: Uma coluna para cada índice definido na aba "Índices" (ex: faixa, voltage, frequency)
Coluna O que preencher Exemplo
mensurando Identificador do mensurando (deve existir na aba Mensurando) acdc
Índices Uma coluna para cada índice definido. Use o label do índice como nome da coluna faixa: 0.022, voltage: 0.002, frequency: 0.01
value Valor numérico do resultado -280
unc Incerteza expandida 44
k Fator de abrangência 2.13
mensurando | faixa | voltage | frequency | value | unc | k acdc | 0.022 | 0.002 | 0.01 | -280 | 44 | 2.13 acdc | 0.022 | 0.002 | 0.02 | 3 | 37 | 2.28 rstdc | | | | 1.23 | 0.01 | 2
Importante: O nome da coluna value na aba Resultados é fixo. Não use o col_name do mensurando aqui — isso é apenas para identificar a coluna de valores numéricos no certificado impresso.

11. Observações

A aba Observações permite adicionar notas e observações adicionais que serão incluídas no certificado.

Esta aba é opcional — se não houver observações, deixe em branco.

Cada linha abaixo do cabeçalho representa uma observação. As observações são numeradas automaticamente (Obs. 1, Obs. 2, etc.).

Observações Observação sobre a condição do equipamento Nota sobre procedimento específico
Dica: Use observações para informações que não cabem em outras seções, como condições especiais de armazenamento, recomendações de recalibração, ou notas sobre limitações do método.
